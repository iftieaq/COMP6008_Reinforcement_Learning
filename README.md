# Residential Energy Management with Reinforcement Learning

COMP6008 Reinforcement Learning group project. We test whether tabular RL agents (Q-learning, SARSA and Expected SARSA) can learn household battery and EV charging decisions that compete with a simple rule-based controller when solar generation, household demand and EV availability are uncertain.

The design (MDP, constants, interfaces) is in [docs/mdp-and-interfaces.md](docs/mdp-and-interfaces.md).

## Setup

Requires Python 3.13 (tested on Linux).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

No external data is needed. All day profiles are generated by `src/scenarios.py`.

## Running

Run the tests (environment, discretisation, baseline, Q-learning):

```bash
python -m pytest
```

Train Q-learning once and compare it with the rule-based baseline (about 80 seconds):

```bash
python src/training.py
```

## Project structure

| Path | Contents |
|---|---|
| `docs/` | Guideline, project plan, MDP and interface specification |
| `src/config.py` | All constants and default hyperparameters |
| `src/scenarios.py` | Day profiles and uncertainty levels |
| `src/environment.py` | Household environment (`gymnasium.Env`) and state discretisation |
| `src/baseline.py` | Rule-based baseline controller |
| `src/agent_common.py` | Shared tabular agent parts (Q-table, epsilon-greedy) |
| `src/q_learning.py` | Q-learning agent |
| `src/training.py` | Training and evaluation loops |
| `tests/` | Sanity checks |

The files in `src/` are assembled into the final notebook, one file per notebook section.
